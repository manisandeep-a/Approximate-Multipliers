# Approximate Multipliers using 4:2 Compressors for Image Processing

# Overview
This project focuses on the design and implementation of approximate multipliers using 4:2 compressors for image processing applications. The objective is to optimize power consumption, delay, and hardware area while maintaining acceptable image quality.

# Objectives
- Design efficient approximate multiplier architecture
- Reduce power and hardware complexity
- Improve computational efficiency for image processing systems
- Analyze image quality using MATLAB

# Technologies Used
- Verilog HDL
- Vivado
- MATLAB
- Cadanece 45nm

# Features
- RTL implementation of approximate multiplier
- 4:2 compressor-based architecture
- Functional simulation and verification
- Image quality analysis
- Performance optimization

# Tools
- Vivado Design Suite
- MATLAB

# Applications
